### Strategy Rationale

The HandlerRegistry is a core routing component that determines which handler processes FUSE operations. This is a high-risk component because:

1. **Data integrity**: Incorrect routing could serve wrong file content
2. **Fallback reliability**: Default handler must always work as safety net
3. **Priority ordering**: Incorrect sorting could cause handler conflicts
4. **Async behavior**: All operations are async with potential race conditions

**Test Level Distribution Justification:**
- Heavy unit coverage for pure logic (registration, sorting, handler selection)
- Integration tests for async dispatch and handler interaction chains
- E2E tests for critical FUSE operations through the full stack

```rust
#[test]
fn test_register_single_handler() {
    let default = mock_default_handler();
```

**5.2-UNIT-003: Unregister by name removes handler**
```rust
#[test]
fn test_unregister_by_name() {
    let mut registry = create_test_registry();
    registry.register(Arc::new(TestHandler::named("target")));
    registry.register(Arc::new(TestHandler::named("keep")));

    registry.unregister("target");

    let names: Vec<_> = registry.list_handlers().iter().map(|(n, _)| *n).collect();
    assert!(!names.contains(&"target"));
    assert!(names.contains(&"keep"));
}
```

#### Detailed Test Specifications

**5.2-UNIT-006: Handlers sorted by priority after registration**
```rust
#[test]
fn test_handler_priority_sorting() {
    let mut registry = create_test_registry();

    // Register out of order
    registry.register(Arc::new(TestHandler::with_priority(100))); // low priority
    registry.register(Arc::new(TestHandler::with_priority(10)));  // high priority
    registry.register(Arc::new(TestHandler::with_priority(50)));  // medium priority

    let priorities: Vec<_> = registry.list_handlers().iter().map(|(_, p)| *p).collect();
    assert_eq!(priorities, vec![10, 50, 100]);
}
```

**5.2-UNIT-007: Lower priority number = higher precedence**
```rust
#[test]
fn test_lower_number_higher_precedence() {
    let mut registry = create_test_registry();
    registry.register(Arc::new(TestHandler::named_with_priority("high", 10)));
    registry.register(Arc::new(TestHandler::named_with_priority("low", 100)));

    let handlers = registry.list_handlers();
    assert_eq!(handlers[0].0, "high");
    assert_eq!(handlers[1].0, "low");
}
```

#### Detailed Test Specifications

**5.2-INT-002: Falls back to default when no handler matches**
```rust
#[tokio::test]
async fn test_fallback_when_no_handler_matches() {
    let fs = mock_fs_with_file("/test.txt", b"default content");
    let mut registry = HandlerRegistry::with_filesystem(fs);

    // Register handler that doesn't match this path
    registry.register(Arc::new(OnlyMatchesJsonHandler));

    let result = registry.handle_read("/test.txt", 0, 100).await.unwrap();
    assert_eq!(result, b"default content");
}
```

**5.2-INT-003: Falls back when handler returns None**
```rust
#[tokio::test]
async fn test_fallback_when_handler_declines() {
    let fs = mock_fs_with_file("/doc.txt", b"fs content");
    let mut registry = HandlerRegistry::with_filesystem(fs);

    // Handler matches but returns None
    registry.register(Arc::new(AlwaysDeclineHandler));

    let result = registry.handle_read("/doc.txt", 0, 100).await.unwrap();
    assert_eq!(result, b"fs content");
}
```

```rust
async fn test_handle_read_dispatches_to_handler() {
    let mut registry = create_test_registry();
    registry.register(Arc::new(InterceptHandler::new("/special/", "intercepted")));

    let result = registry.handle_read("/special/file.txt", 0, 100).await.unwrap();
    assert_eq!(String::from_utf8(result).unwrap(), "intercepted");

```

**5.2-INT-006: handle_write dispatches to matching handler**
```rust
#[tokio::test]
async fn test_handle_write_dispatches_to_handler() {
    let mut registry = create_test_registry();
    let write_handler = Arc::new(CapturingWriteHandler::new());
    registry.register(write_handler.clone());

    let written = registry.handle_write("/capture/test.txt", 0, b"data").await.unwrap();

    assert_eq!(written, 4);
    assert_eq!(write_handler.captured(), b"data");
}
```
