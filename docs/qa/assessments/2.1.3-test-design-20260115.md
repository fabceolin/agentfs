# Test Design: Story 2.1.3 - Template Conformance and Status Normalization

Date: 2026-01-15
Designer: Quinn (Test Architect)

## Test Strategy Overview

- Total test scenarios: 32
- Unit tests: 20 (62.5%)
- Integration tests: 10 (31.25%)
- E2E tests: 2 (6.25%)
- Priority distribution: P0: 10, P1: 14, P2: 8

## Rationale

This story has higher complexity due to:
- Status normalization with many edge cases (real-world variant patterns)
- Template detection across filesystem
- Embedding-based matching (external dependency on TEA)
- Multi-file directory scanning

E2E tests are warranted for the directory scanning flow to ensure all components work together.
