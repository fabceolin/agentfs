## Test Scenarios by Acceptance Criteria

### AC1: Trait `EmbeddingGenerator` with Async Methods

**Requirement:** Core trait defining async embedding generation interface.

| ID | Level | Priority | Test Description | Justification |
|----|-------|----------|------------------|---------------|
| 2.1-UNIT-001 | Unit | P0 | Trait method signatures compile correctly | Validates trait design at compile time |
| 2.1-UNIT-002 | Unit | P1 | Default `generate_batch` sequential implementation | Pure logic, no external deps |
| 2.1-UNIT-003 | Unit | P1 | `should_embed` returns false for content < 10 chars | Simple predicate logic |
| 2.1-UNIT-004 | Unit | P2 | `max_content_length` default returns 8191 | Configuration constant validation |
| 2.1-INT-001 | Integration | P1 | Trait object dynamic dispatch works across implementations | Tests trait bounds (Send + Sync) |

#### Detailed Scenarios

**2.1-UNIT-001: Trait Method Signatures**
```
Given: A struct implementing EmbeddingGenerator
When: Compiling the implementation
Then: All required methods (generate, model_name, dimension) must be implemented
And: Default methods (generate_batch, should_embed, max_content_length) are available
```

**2.1-UNIT-002: Default Batch Implementation**
```
Given: An EmbeddingGenerator with custom generate()
When: generate_batch() is called with 3 items
Then: generate() is called 3 times sequentially
And: Results are returned in same order as input
```

**2.1-UNIT-003: Should Embed Filter**
```
Given: Default should_embed() implementation
When: Called with content "short" (5 chars)
Then: Returns false
When: Called with content "long enough content" (18 chars)
Then: Returns true
```

### AC5: Chunked Embedding Strategy for Large Files

**Requirement:** Handle files exceeding model's context window via chunking with overlap.

| ID | Level | Priority | Test Description | Justification |
|----|-------|----------|------------------|---------------|
| 2.1-UNIT-013 | Unit | P0 | `split_chunks()` produces overlapping segments | Core chunking algorithm |
| 2.1-UNIT-014 | Unit | P0 | All chunks respect max chunk_size | Boundary validation |
| 2.1-UNIT-015 | Unit | P1 | Content smaller than chunk_size produces single chunk | Edge case handling |
| 2.1-UNIT-016 | Unit | P1 | Overlap calculation preserves context continuity | Algorithm correctness |
| 2.1-INT-009 | Integration | P0 | `generate_aggregated()` averages chunk embeddings | End-to-end chunking |
| 2.1-E2E-001 | E2E | P0 | Large file write triggers chunked embedding update | DuckAgentFS integration |
| 2.1-E2E-002 | E2E | P1 | fs_embeddings table populated correctly | Persistence validation |
| 2.1-E2E-003 | E2E | P2 | Binary file skipped (no embedding generated) | Filter behavior |

#### Detailed Scenarios

**2.1-UNIT-013: Chunk Splitting Algorithm**
```
Given: ChunkedEmbedding with chunk_size=10, overlap=2
When: split_chunks("hello world this is a test") called
Then: Multiple chunks returned
And: Each chunk has overlap with adjacent chunks
And: First characters of chunk[n] match last `overlap` chars of chunk[n-1]
```

**2.1-UNIT-014: Chunk Size Enforcement**
```
Given: ChunkedEmbedding with chunk_size=100, overlap=10
When: split_chunks(long_content) called
Then: All returned chunks have length <= 100
And: No content is lost between chunks
```

**2.1-UNIT-015: Single Chunk for Small Content**
```
Given: ChunkedEmbedding with chunk_size=1000
When: split_chunks("small text") called
Then: Returns exactly 1 chunk
And: Chunk content equals original content
```

**2.1-INT-009: Aggregated Embedding**
```
Given: ChunkedEmbedding wrapping a generator
When: generate_aggregated(large_content) called
Then: Content is split into chunks
And: Each chunk gets individual embedding
And: Final embedding is element-wise average of all chunk embeddings
And: Dimension matches underlying generator
```

**2.1-E2E-001: DuckAgentFS Large File Integration**
```
Given: DuckAgentFS with VSS enabled and embedding generator
When: A text file > max_content_length is written
Then: update_embedding() is triggered
And: ChunkedEmbedding produces aggregated vector
And: Embedding stored in fs_embeddings table
```
