# Test Design: Story 5.4 - FUSE Integration

Date: 2026-01-16
Designer: Quinn (Test Architect)

## Test Strategy Overview

- Total test scenarios: 38
- Unit tests: 16 (42%)
- Integration tests: 18 (47%)
- E2E tests: 4 (11%)
- Priority distribution: P0: 12, P1: 17, P2: 9

## Story Context

**STORY-5.4: FUSE Integration** implements two phases:
1. **Phase 1 (Complete)**: Handler Registry integration into FUSE operations
2. **Phase 2 (New)**: Tera Rendering Mode with xattr-controlled read/write behavior

The Phase 2 implementation introduces a novel approach where markdown files can be read in either rendered (Tera-processed) or raw mode, controlled via extended attributes.

## Test Implementation Recommendations

### Unit Test Framework

```rust
// Example test structure for Phase 2 unit tests
#[cfg(test)]
mod tera_rendering_tests {
    use super::*;

    #[test]
    fn test_should_render_returns_false_when_raw_mode() {
        // Given: A FUSE instance with xattr cache
        let fuse = create_test_fuse();
        let ino = 123;
        fuse.xattr_cache.lock().insert(ino, true); // raw=1

        // When: Checking if path should render
        let should_render = fuse.should_render("/test.md", ino);

        // Then: Should not render in raw mode
        assert!(!should_render);
    }

    #[test]
    fn test_render_error_returns_graceful_content() {
        // Given: Invalid Tera syntax
        let raw_content = b"# Hello {% invalid %}";

        // When: Rendering with timeout
        let result = render_with_timeout(raw_content, Duration::from_secs(5));

        // Then: Should return error comment + raw content
        assert!(result.contains("<!-- Render Error:"));
        assert!(result.contains("{% invalid %}"));
    }
}
```

### Integration Test Framework

```rust
// Example integration test for FUSE xattr behavior
#[tokio::test]
async fn test_write_blocked_in_rendered_mode() {
    // Given: Mounted FUSE filesystem with .md file
    let mount = create_test_mount().await;
    let path = mount.path().join("test.md");

    // When: Attempting to write without setting raw mode
    let result = std::fs::write(&path, "new content");

    // Then: Should fail with EACCES
    assert!(result.is_err());
    let err = result.unwrap_err();
    assert_eq!(err.raw_os_error(), Some(libc::EACCES));
}
```

### E2E Test Framework

```bash
#!/bin/bash
# E2E test: xattr toggle behavior

# Setup
agentfs init test-agent
agentfs mount test-agent /tmp/test-mount &
sleep 1

# Create file (should default to raw mode and be writable)
echo "# {{ title }}" > /tmp/test-mount/doc.md

# Verify default rendered read
content=$(cat /tmp/test-mount/doc.md)
if [[ "$content" == *"{{"* ]]; then
    echo "FAIL: Default read should be rendered"
    exit 1
fi

# Toggle to raw mode
setfattr -n user.agentfs.raw -v 1 /tmp/test-mount/doc.md

# Verify raw read
content=$(cat /tmp/test-mount/doc.md)
if [[ "$content" != *"{{"* ]]; then
    echo "FAIL: Raw mode should return template syntax"
    exit 1
fi

echo "PASS: xattr toggle behavior"
```
