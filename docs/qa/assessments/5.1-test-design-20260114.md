# Test Design: Story 5.1 - FileHandler Trait

**Date:** 2026-01-14
**Designer:** Quinn (Test Architect)

## Test Strategy Overview

- **Total test scenarios:** 24
- **Unit tests:** 16 (67%)
- **Integration tests:** 6 (25%)
- **E2E tests:** 2 (8%)
- **Priority distribution:** P0: 8, P1: 10, P2: 4, P3: 2

## Story Context

The FileHandler trait provides an extensible system for intercepting FUSE operations on specific file patterns. This is foundational infrastructure that all handler implementations depend on.

**Risk Assessment:** HIGH - Core trait affecting all FUSE operations; incorrect behavior cascades to all handlers.

## Detailed Test Specifications

### Unit Tests

#### 5.1-UNIT-001: Async Trait Implementation
```rust
#[tokio::test]
async fn test_trait_can_be_implemented_async() {
    struct TestHandler;

    #[async_trait]
    impl FileHandler for TestHandler {
        fn name(&self) -> &str { "test" }
        fn can_handle(&self, _: &str, _: Option<&Stats>) -> bool { true }

        async fn read(&self, _: &str, _: u64, _: u64) -> HandlerResult<Vec<u8>> {
            Ok(Some(b"test".to_vec()))
        }
    }

    let handler = TestHandler;
    let result = handler.read("/test", 0, 100).await;
    assert!(result.is_ok());
    assert!(result.unwrap().is_some());
}
```

#### 5.1-UNIT-005: Default Priority
```rust
#[test]
fn test_default_priority_is_100() {
    struct MinimalHandler;

    impl FileHandler for MinimalHandler {
        fn name(&self) -> &str { "minimal" }
        fn can_handle(&self, _: &str, _: Option<&Stats>) -> bool { false }
    }

    let handler = MinimalHandler;
    assert_eq!(handler.priority(), 100);
}
```

#### 5.1-UNIT-006: Priority Ordering
```rust
#[test]
fn test_priority_ordering_lower_is_higher() {
    struct HighPriority;
    struct LowPriority;

    impl FileHandler for HighPriority {
        fn name(&self) -> &str { "high" }
        fn priority(&self) -> u32 { 10 }
        fn can_handle(&self, _: &str, _: Option<&Stats>) -> bool { true }
    }

    impl FileHandler for LowPriority {
        fn name(&self) -> &str { "low" }
        fn priority(&self) -> u32 { 100 }
        fn can_handle(&self, _: &str, _: Option<&Stats>) -> bool { true }
    }

    let high = HighPriority;
    let low = LowPriority;

    // Lower number = higher priority (tried first)
    assert!(high.priority() < low.priority());
}
```

### Integration Tests

#### 5.1-INT-001: Handler Registry Sorting
```rust
#[test]
fn test_registry_sorts_by_priority() {
    let mut registry = HandlerRegistry::new();

    registry.register(Box::new(LowPriorityHandler));   // priority 100
    registry.register(Box::new(HighPriorityHandler));  // priority 10
    registry.register(Box::new(MedPriorityHandler));   // priority 50

    let handlers = registry.handlers_for_path("/test");

    assert_eq!(handlers[0].priority(), 10);
    assert_eq!(handlers[1].priority(), 50);
    assert_eq!(handlers[2].priority(), 100);
}
```

#### 5.1-INT-005: Ok(Some) Stops Chain
```rust
#[tokio::test]
async fn test_ok_some_stops_chain() {
    let mut registry = HandlerRegistry::new();

    registry.register(Box::new(AcceptHandler::new("first")));
    registry.register(Box::new(AcceptHandler::new("second"))); // Should NOT be called

    let result = registry.read("/test", 0, 100).await.unwrap();

    assert_eq!(result, b"first");
}
```

#### 5.1-INT-006: Ok(None) Passes to Next
```rust
#[tokio::test]
async fn test_ok_none_passes_to_next() {
    let mut registry = HandlerRegistry::new();

    registry.register(Box::new(DeclineHandler));         // Returns Ok(None)
    registry.register(Box::new(AcceptHandler::new("fallback")));

    let result = registry.read("/test", 0, 100).await.unwrap();

    assert_eq!(result, b"fallback");
}
```

### E2E Tests

#### 5.1-E2E-001: Error Propagation to FUSE
```rust
#[tokio::test]
async fn test_error_propagates_as_fuse_error() {
    // Mount FUSE filesystem with error-throwing handler
    let mount = test_mount_with_handler(ErrorHandler::new(libc::ENOENT));

    // Attempt to read file
    let result = std::fs::read(mount.path().join("error_file"));

    assert!(result.is_err());
    assert_eq!(result.unwrap_err().raw_os_error(), Some(libc::ENOENT));
}
```
